# 판매 페이지 이미지 컷 분리 도구

판매 페이지 주소를 입력하면 페이지를 브라우저처럼 열고, 전체 캡처를 만든 뒤 세로 구간으로 잘라 아래 폴더에 자동 저장합니다.

기본 저장 위치:

```text
C:\Users\kikuke\OneDrive\바탕 화면\AAA\판매 페이지\sample_image
```

상품명이 `핸드로션`이면 결과 구조는 이렇게 만들어집니다.

```text
sample_image/
  핸드로션/
    01_대표컷/
    02_제품_확인컷/
    03_핵심_장점컷/
    04_디테일컷/
    05_사용_상황컷/
    06_신뢰_구매_설득컷/
    99_미분류/
    _전체캡처/
    분류_결과.json
```

## 실행 방법

PowerShell에서 이 폴더로 이동한 뒤 실행합니다.

```powershell
.\run_sale_page_cutter.ps1
```

또는 바로 실행할 수 있습니다.

```powershell
& "C:\Users\kikuke\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" .\sale-page-cutter.js --url "판매페이지주소" --product "핸드로션"
```

## 현재 버전의 특징

- 원본 이미지 주소를 다운로드하지 않고, 실제 화면에 보이는 판매 페이지를 캡처합니다.
- 스크롤로 lazy-load 이미지를 최대한 불러온 뒤 전체 페이지를 저장합니다.
- 흰 여백과 길이를 기준으로 상세페이지를 여러 컷으로 자릅니다.
- 페이지 안의 일반 텍스트를 참고해 대표컷, 제품 확인 컷, 핵심 장점 컷, 디테일 컷, 사용/상황 컷, 신뢰/구매 설득 컷으로 자동 분류합니다.

## Vercel 웹 버전

Vercel에서는 `index.html` 화면이 열립니다. 판매 페이지 URL과 상품명을 입력하면 `/api/cut` 서버 함수가 페이지를 캡처하고 컷 단위로 분리한 뒤 ZIP 파일로 다운로드합니다.

브라우저 보안상 웹사이트가 사용자 PC의 `C:\...` 폴더에 직접 이미지를 조용히 저장할 수는 없습니다. 웹 버전은 결과를 `상품명.zip`으로 내려받는 방식입니다.

## 참고

이미지 안에 박혀 있는 글자는 첫 버전에서 완벽하게 읽지 못할 수 있습니다. 실제 판매 페이지 URL로 테스트한 뒤, 쇼핑몰 구조에 맞춰 분류 기준을 더 정교하게 조정하면 정확도가 올라갑니다.
